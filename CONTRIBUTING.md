# Contributing

Contributions should make the library more useful to AI video creators. Submit
prompts that are clear, structured, and based on a workflow you understand.

## What to Include

- Prompt title
- Wan 3.0 prompt
- Category
- Workflow, such as Text-to-Video, Image-to-Video, or Start & End Frame
- Optional negative prompt
- Optional generation notes or known limitations

Do not claim that a prompt has been tested unless you have generated a result
with it. A public result is helpful but is not required.

You must have the right to share all submitted prompts and reference material.
Do not copy another creator's work without permission or clear attribution. Do
not submit private or personally identifying source material without permission.

## Submission Template

````markdown
# Prompt Title

Short description.

## Overview

- **Model:** Wan 3.0
- **Category:**
- **Workflow:**
- **Style:**

## Prompt

```text
Your prompt
```

## Negative Prompt

Include only when one is genuinely part of the workflow.

## Notes

Optional generation notes, limitations, or attribution.
````

## Style Guidelines

- Use concise, natural English.
- Keep instructions specific enough to be actionable.
- Separate image prompts from video prompts.
- Do not invent settings, results, or model capabilities.
- Avoid promotional copy and keyword stuffing.
- Preserve attribution for adapted work.

By contributing original material, you agree that it may be distributed under
the repository's [CC BY 4.0 license](LICENSE).
