# Awesome Wan 3.0 Video Prompts

A curated and growing collection of structured Wan 3.0 prompts for cinematic
scenes, product commercials, camera movement, character animation,
transformations, and multi-shot storytelling.

The collection focuses on prompts that are readable, adaptable, and useful as
starting points for real creative workflows. It is maintained by
wan3video.co.

**Try these prompts with [Wan 3.0 online](https://wan3video.co/).**

## What You'll Find

- Cinematic direction and intentional camera movement
- Character performance and identity-preservation instructions
- Product commercial concepts and physical constraints
- Start & End Frame transformation workflows
- Negative prompts where they are part of the original material
- Long-form, multi-shot storytelling prompts

## Prompt Structure

Each entry includes an overview, the prompt itself, a short explanation of its
construction, and practical adaptation tips. Multi-step workflows keep image
and video instructions separate instead of combining them into one block.

## How to Use These Prompts

1. Open a prompt from the library table.
2. Copy the relevant prompt block for your workflow.
3. Replace subjects, environments, brands, or camera choices as needed.
4. Add reference media only when the workflow calls for it and you have the
   right to use that media.
5. Generate, review, and refine. Outputs may vary between runs, model versions,
   settings, and source materials.
